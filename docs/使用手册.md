# 使用手册

把照片 / 插图变成像素画，再逐格精修，最后出拼豆图纸或游戏素材。**全部处理在你自己的电脑上完成。**

## 快速开始

1. 双击 `像素画工作台.html`（建议 Chrome / Edge）
2. 拖入图片（或顶栏「导入图片」，也可 `Ctrl+V` 粘贴）
3. 右侧点一个预设（或手动调参）→ 左侧工具精修 → 顶栏「导出 ▾」

支持格式：PNG / JPG / WebP / GIF / BMP / AVIF / ICO / SVG（浏览器原生解码）。

## 三种用途：点预设，不用切模式

工作台只有**一套**转换引擎。图片→像素 / 拼豆图纸 / 游戏资产这三种用途，本质是**三组不同的参数**，
所以它们以**右侧「预设」**的形式提供——顶栏不再有"工作模式"选择器（原先那三个模式只是在切参数，
还会互相残留，现已与预设合并）。

| 用途 | 点哪个预设 | 这套预设替你设好什么 |
|---|---|---|
| 通用转换（照片 / 插图） | **照片写实**（或 GameBoy / 复古主机 / 黑白剪影） | 自动取色或预置色卡，长边格数按比例 |
| 手工拼豆 | **拼豆图纸** | 拼豆号色卡 + **锁定色板**（只用买得到的颜色）+ 不抖动 + 长边 58 格（约一块大方板） |
| 引擎素材（精灵 / 图标） | **游戏精灵** | **精确尺寸** 32×32 + 真 alpha + 最近邻降采样 + 不做杂色清理 |

预设就是"一键套一整套参数"，套完仍可自由微调；要改预设本身，见下文「预设（可改、可存）」。

## 顶栏

顶栏只有两处内容：**左侧是品牌**，**右上角是全部动作**。窗口变窄时动作按钮自动收成图标（悬停有说明）。

| 位置 | 内容 |
|---|---|
| 左侧 | 品牌（三种用途已并入右侧**预设**，不再有工作模式选择器） |
| 右上角 | 撤销 · 重做（无步骤时自动变灰）· 重新转换 · 新建 · **导入图片** · **导出 ▾** ｜ 最右侧：`? 快捷键` |

### 还没有画布时怎么开始

三种方式，任选其一（**都指向同一件事：建一张空白画布**）：

| 方式 | 位置 |
|---|---|
| **点空状态里的「✚ 新建空白画布」** | 画布区正中间，没画布时最显眼 |
| **点顶栏「✚ 新建」** | 还没有画布时它会**直接建一张**（有画布时才变成"确认后清空"） |
| **导出 ▾ → 画布 → 新建空白画布** | 导出菜单里 |

空白画布的尺寸取当前参数：**「尺寸方式 = 精确尺寸」时用那个 W×H**，否则用「长边格数」且不超过 58；
底色取「合成底色」，勾了「透明处理 = 真 alpha」就是透明底。想换尺寸，建完在右侧「参数」面板里改，或直接拖图片进来重新转换。

> 曾经「新建」在没有画布时是**灰的**，而唯一的空白画布入口藏在「导出 ▾」里——
> 第一次打开工作台的人会卡在这里（"新建点不了、又不知道去哪建"）。现在按钮不再禁用，空状态也直接给出入口。

**导出 ▾** 菜单里按用途分组：

- **图片**：PNG 1x（原尺寸）、放大倍数 1x–20x 一键、复制 PNG 到剪贴板
- **拼豆**：图纸 SVG + 缺口清单 CSV
- **数据**：像素数据 JSON、项目 JSON
- **画布**：新建空白画布（不导入图片直接开画）

没有画布时菜单仍可点开，里面会直接说明该先做什么（而不是按钮变灰让人猜）。
`Ctrl+S` 等于「导出 PNG 1x」。

### 侧栏的折叠 / 展开箭头

两侧面板**各有一个折叠开关**，浮在**面板外面的画布边上、顶端**：
左栏的箭头在画布左上角（紧贴左栏右缘），右栏的箭头在画布右上角（紧贴右栏左缘）。
图标是一个**三角形箭头**，指向"点下去会往哪收"：

| 状态 | 左栏箭头 | 右栏箭头 | 点一下 |
|---|---|---|---|
| 展开 | ◀（往左收） | ▶（往右收） | 把这一栏收起，画布占满那块空间 |
| 收起 | ▶（往右展开） | ◀（往左展开） | 把这一栏展开 |

箭头**浮在栏外**，所以面板收起时箭头不会跟着消失——它就在原处（栏收起后自然贴到画布/屏幕边上），
点一下即可放回来。

两种窗口宽度下的"展开"形态不同，但都是同一套箭头与同一个动作：

| 窗口宽度 | 展开时 | 收起时 |
|---|---|---|
| 宽（>980px） | 常驻左右两列 | 该列整栏收起，**两侧各自独立**，可只收一边、也可都收起让画布占满 |
| 窄（≤980px） | 浮在画布上的抽屉（带遮罩） | 收起；**一次只开一个**抽屉（同时开两个会互相遮挡） |

窄屏下点遮罩或按 `Esc` 会把抽屉收起来。窄屏初始状态是两侧都收起。

```
宽屏：初始        [工具 232] [ 画布 ] [参数 300]     箭头贴在画布两上角
点左栏 ◀          [  收起  ] [   画布   ] [参数 300]
再点右栏 ▶        [  收起  ] [   画布   ] [  收起  ]   ← 两个都收起，画布占满
```

> 这块交互历史上坏过三次，都是"没有错误信号"的类型：
> 1. `.narrow-only` 样式**从来没有被写出来**（只出现在 HTML 和注释里），
>    于是宽窗口下顶栏那两个按钮照常显示，而点击改的状态桌面布局不读——"按了没反应"。
> 2. 修好后折叠状态存成了**单个三值变量**，四个组合里"两边都收起"不可达：
>    关第二个时第一个会被顶回来。现在两侧各存一个布尔量。
> 3. 开关一度放进栏内，于是收起只能做成"窄边"（否则开关自己也没了）；
>    现在开关浮在栏外，收起就是干净地整栏隐藏，不留空窄边。
>    **代价是隐藏一栏时必须同时把网格模板改成两列**——`display:none` 会把那个网格项
>    从布局里摘掉、剩下两项自动重排，只改 `display` 会得到"画布宽度变成 0"。

## 转换参数

参数面板按用途分成 **10 个可折叠分组**，点标题栏即可展开/收起（三角 ▾／▸ 跟着翻）：

- **预设默认展开**，其余 9 组（尺寸 / 裁剪 / 色板 / 降采样 / 抖动 / 杂色清理 / 图像调整 / 透明处理 / 显示）**默认收起**——
  大多是调好一次就不再动的次要项，收起来面板才不至于很长。
- 折叠状态**记在本机**（localStorage），下次打开保持你的选择。

| 参数 | 说明 |
|---|---|
| 尺寸方式 | **长边格数（按比例）** 或 **精确尺寸 W×H**。切到精确时写入 W×H；**切回长边会清掉精确尺寸**（否则长边控件调了没效果） |
| 长边格数 | 输出长边格数（8–2048），短边按原图比例取整 |
| 画布尺寸（格） | 精确模式下的 W×H，帧尺寸恒等。常见：拼豆方板 58×58（29×29 孔）、游戏资产 16/24/32/48/64/128 |
| 色板 | **自动提取**（Median Cut）/ **预置色卡**（19 张，下拉按来源分三组：主机硬件色表 4 张 · 品牌拼豆 13 张 · 通用近似 2 张）/ **自定义**；支持导入 `.hex`（Lospec 风格，或 `编号 #rrggbb` 两列带号色）。<br>**导入后会出现「号色表」**：逐色显示 `号色 / 色块 / hex`，可直接改号色（改完按回车或点别处），也可点「删」移除不要的颜色（颜色与号色一起删，编号不会错位） |
| 降采样 | 区域平均（照片）／最近邻（硬边） |
| 抖动 | 关闭 / Floyd–Steinberg / **Atkinson** / Bayer 4×4 / **Bayer 8×8**；**开启时杂色清理自动关闭**（抖动点会被清理吞掉）。<br>Atkinson 只扩散 3/4 误差、主动丢弃 1/4：色点更干净、色号更少，在有限色板上往往比 F-S 好看。抖动**会增加色号数与珠子数**——那是直接的买豆成本，可用「色号上限」压住 |
| 杂色清理 | 把孤立小色块并入邻域主色，适合让色块成形 |
| 色号上限 | 抖动时最多用到几种色号（0=不限）。给「我手上只有 14 种豆子」这类约束用：超限时自动收敛到用量最大的那些色，**约束是硬的** |
| 亮度 / 对比度 / 饱和度 | 转换前调整；照片发灰先加对比度。三项各一条**滑条**（-100…100，0 在中位，填充从中点向两侧生长）；**拖动时画面实时更新**，松手才落成一次编辑；右侧数值框也可直接输入（回车或点别处生效）。**按住后可以拖出滑条甚至拖到面板外**——上下晃不会掉、不会选中文字，光标全程保持左右箭头 |
| 透明处理 | **不透明**（合成到底色）／**单色键控**（导出时该色变透明）／**真 alpha**（保留原图透明，精灵图首选） |
| 合成底色 | 「不透明」时把原图透明区合成到这个颜色；「单色键控」时它是被扣掉的键控色。**点色块会在字段下方就地展开取色盘**（与主色/背景色同一套 Blender 式取色器），不再是系统调色板；再点一次收起 |
| 锁定色板 | 只用给定色板，绝不新增颜色（拼豆与资产批次必备） |

### 预设（可改、可存）

**「预设」本身也是一个可折叠分组**（标题栏与其他分组长得一样，点一下可收起）。
它默认展开——这是切换三种用途（图片→像素 / 拼豆图纸 / 游戏资产）最直接的入口。

一排预设按钮，点一个就套一整套参数：

- **照片写实 / GameBoy / 复古主机 / 黑白剪影 / 游戏精灵 / 拼豆图纸** 是**出厂预设**。
- 下方的 **「管理预设 ▾」** 展开后每个预设一行：
  - **用当前参数更新**：把参数面板里现在这套参数**写回**该预设（之后它的按钮上会出现一个圆点角标，表示"已改过"）；
  - **恢复出厂**：丢掉你的改动，回到出厂参数；
  - **删除**：只对自定义预设出现。
- **「＋ 存为预设」**：把当前参数存成一个**新预设**（会问你名字）。自定义预设带 ★ 与虚线框。

两点要知道：

- 套用预设是**替换**而不是叠加——点了「拼豆图纸」不会残留上一套的精确尺寸或锁定色板。
- 你的改动只存在**本机浏览器**（localStorage），不进项目文件；页面脚本用的页内 API 报的始终是**出厂预设**。

| `U` / `O` | 矩形 / 椭圆（拖拽绘制） |

| `Tab` | 交换主色 / 背景色 |
| `Alt + 点击` | 临时取色（不切换工具） |
| 按住 `L` 点击 | 从上次落笔处画直线 |
| `M` 拖动 | 框选（`Shift` 并入选区，可从画布外起手） |
| `X` / `Del` / `Backspace` | 把选区挖成透明 |
| `F` | 选区填主色 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选区（粘贴锚点为鼠标所在格） |
| 方向键 / `Shift+方向键` | 移动选区内容 1 / 10 格 |
| 滚轮 / `+` / `−` / `0` | 缩放 / 适配窗口 |
| 空格 + 拖动、中键拖动 | 平移画布 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做（上限：**50 步 或 累计 64MB**，先到先算——大画布上能撤的步数会相应变少，这样弱机也不会吃满内存） |

| `?` | 打开快捷键速查表（与顶栏最右侧那个按钮等效） |

- **左键画主色，右键画背景色**；笔刷 1×1 / 2×2 / 3×3（悬停有足迹预览）。
- 选区在状态栏显示格数；有复制内容时会显示「已复制选区」。
- 缩放与适配全走快捷键：`0` 适配窗口、`+` / `−` 缩放、滚轮以鼠标为中心缩放、空格 / 中键拖动平移。
- 顶栏 `? 快捷键` 打开速查表——**以它为准**。
- 焦点在输入框 / 下拉框 / 勾选框上时，全局快捷键会主动让路（免得打字时误触发）；先点一下画布再按。

## 取色器

点左栏的**主色 / 背景色色块**即展开取色器，按 **Blender 取色界面**的结构组织。

**收起有三种方式**：再点一次那个色块（色块提示语会跟着变成「点击收起取色器」）、
点面板底部的「收起」按钮、或点另一个色块**切过去**继续调。
> 「主色 → 背景」这样连点两个色块是**切换编辑目标**、不会收起；只有点**当前正在调的那一路**才是收起。

参数面板里的**合成底色**色块打开的是**同一套取色盘**，但它**就地展开在该字段下方**（不在左侧）。

两者的**吸管按钮去向不同**（提示语会写明）：左侧色盘的吸管取到的颜色进主色/背景色；
合成底色色盘的吸管是**一次性**的——取一格后该颜色写进「合成底色」并自动退出吸管（还原你原先用的工具）。
两种吸管都可以按 `Esc` 取消。

```
┌ [ RGB | HSV ] ─────────────────┐   ← 顶部只有两段标签（Hex 不是标签，见下）
│       ╭──────────╮   ┌──┐       │
│       │   色轮   │   │  │       │   ← 左：圆形色轮（中心白、外圈饱和）
│       ╰──────────╯   └──┘       │   ← 右：明度竖条（上亮下暗）
│  红  ████████   0.278           │   ← 数值行：轨道填充 = 数值比例，
│  绿  ██████     0.447           │     数值框在**轨道右侧之外**（拖动碰不到它）
│  蓝  ███████    0.702           │
│  透明度 ████████ 0.000          │   ← 两态：左半边 = 1.000 全透明，右半边 = 0.000 实色
│  Hex [ #4772B3 ]          [吸管] │   ← Hex 行**常驻**，右侧是吸管按钮（内联 SVG 图标）
│  本图 ■■■■■■■ / 最近 ■■■■ / 预置 ■■■■ │   ← 色板：本图用色 / 最近使用 / 预置色卡
└─────────────────────────────────┘
```

| 操作 | 说明 |
|---|---|
| 色轮拖动 | 角度 = 色相，半径 = 饱和度；拖到圆外饱和度自动夹满 |
| 明度竖条 | 上下拖动改明度（V），上方更亮 |
| 数值行（红/绿/蓝 或 色相/饱和度/明度） | 整行都是滑条，拖动即改；右侧数值框可手输（显示是归一化 0–1 三位小数，输入兼容 0–255 / 0–100 / 0–360 旧刻度） |
| 透明度行 | **拖到左半边 = 选中「透明色」**（画笔/填充/形状即挖洞），拖到右半边 = 实色；以中线分界，整条轨道都有响应 |
| 顶部标签 | `RGB` / `HSV` 切换数值行的单位；改哪个都实时生效 |
| Hex 行 | **常驻**在数值行下方（不属于任何标签段），直接输入 6 位十六进制 |
| 色板 | 点任一色块即设为主色（含拼豆号色卡） |
| 吸管按钮 | 点 Hex 行右侧的吸管图标，再到画布上点一格取色（等同于取色工具 `I`） |

**拖动过程中不会把每个中间色都记进撤销栈**，松手才提交一次；窗口失焦时会自动收尾，不会出现"拖拽卡住"。

> 取色器的配色沿用 Blender 那套深灰 + 蓝色强调（`#4772b3`）；界面其余部分保持原有深灰主题。

## 改画布上已有的颜色（工作色板）

左栏「工作色板」里的色块**左键选为主色**，**右键**弹出两项：

| 菜单项 | 做什么 |
|---|---|
| **微调此颜色…** | 改这个颜色**本身**。全图凡是用到它的格子一起变——适合"这个色调不太对，微调一下" |
| **替换为…** | 把用到它的格子**换成另一个颜色**。适合"图纸上这个色我没有，换成手上有的一色"（拼豆场景） |

两项都会在色块下方**就地展开取色器**（与主色/背景色同一套 Blender 式界面），此时：

- **拖动色轮 / 滑条，画面实时跟着变**——不用来回确定，看到满意为止；
- **「完成」= 提交**，一次编辑只记**一条撤销**（中间拖多少下都算同一次）；
- **Esc = 放弃**，画面还原成改之前的样子，**不占用撤销**（等于没发生过）；
- **直接去改另一个色块（或再点一次同一格）等于"完成"**：上一处改好的颜色会自动提交，
  不会被丢掉。只有 Esc 才是放弃；
- 正在编辑的那个色块会加一圈虚线高亮，编辑器标题也写明正在改哪个色。

**「微调」遇到重复色会自动合并**：如果你把某个色调成了色板里已有的另一个颜色，
那两项会并成一项（原来的那一项被移除，用到它的格子改指合并后的项）。
这样做是为了让拼豆图纸上**同一个颜色不会印出两个号色**——那会让人以为要买两包。
合并同样可撤销。

> 「替换为…」不会删掉源色那一项，它会留在色板里变成**零用量**的暗色块（`.unused` 样式）。
> 这是既有语义：色板条目只增不减，避免下标错位。想收拾干净可以用「微调」把它调成别的色。

## 参数滑条（亮度 / 对比度 / 饱和度）

三项各一条滑条，**按住拖动时画面实时更新**，松手即成一次编辑。另外：

- 按住后可以**拖出滑条甚至拖到面板外**——上下晃不会掉，光标全程保持左右箭头，也不会选中沿途文字；
- 拖过头了**反向拖回去**即可。参数没有撤销栈，所以这里没有"一步取消"。

## 导出

| 产物 | 内容 |
|---|---|
| PNG（1x–20x） | 整数倍最近邻放大，格子锐利；尺寸超限自动降倍 |
| 复制 PNG | 1 倍复制到剪贴板，可直接粘进聊天/文档 |
| 像素 JSON | 每格颜色 + **每色用量表**（拼豆原料清单、素材核对） |
| 项目 JSON | 参数 + 色板 + 像素，**不含原图**，体积小可分享；对方重新导入原图即可再转换 |
| 拼豆图纸 SVG | 格内标号色、每 10 格加强线、板编号与图例；屏幕上缩放查看很方便 |
| **拼豆图纸 PDF** | **A4 分页、每块板一页**，含格内号色与图例。要**打印出来照着摆**就用它（纸张尺寸与分页是确定的） |
| 缺口清单 CSV | 编号 / 颜色 / 格数 / 珠数 / 估算重量 / 建议袋数 |
| `.hex` 色板 | 可导入 Lospec 等工具 |

文件名自动带源图名，例如 `照片_64x48_8x.png`。

> **SVG 与 PDF 怎么选**：屏幕上查看 / 发给别人改 → SVG；**打印**或需要确定的纸张尺寸 → PDF。
> 两者的格内号色与清单完全一致（同一套色卡），可以混用。
>
> **PDF 怎么排版**（自适应 A4）：
> - **默认把整幅缩放进一页**，格子大小按可用纸张自动算，所以**多数情况下不跨页**。
> - 只有整幅缩到格子印不清时（约小于 1.5mm/格），才**按板分页**——每页一块板、格子放到最大。
>   这是刻意的取舍：把 16 块板的图纸硬塞进一页只会糊成一片，不如分页但看得清。
> - 实测：16×16 / 32×32 / 58×58 / 120×120 都是 **1 页**；200×200 起按板分页。
> - 缩放过时页眉会标出实际格边长（如 `cell 3.28 mm`），方便你判断要不要换尺寸。
>
> PDF 的页内标题是英文（如 `Bead Pattern 58x58`）：PDF 内置字体只支持 ASCII，
> 中文会变成乱码，所以宁可显示英文也不给一份乱码文档；**文件名仍然是中文的**。
> 导出 PDF 需要较新的 Chrome / Edge（用到 `CompressionStream`），
> 不支持时会明确提示并建议改用 SVG，而不是产出一份打不开的文件。

## 拼豆用户注意

- 默认每板 **58×58 格**（对应 29×29 孔的大方板）；可按你的板子规格调整（`--board` 或用页内 API 的 `boardCells`）。
- 重量按 **5mm 豆 / 单颗约 0.08g** 估算，可用 `--bead-mm` / `--bead-gram` 改成你自己的规格。
- 内建色卡分三类来源：**主机硬件色表**（PICO-8/GameBoy/NES/CGA，官方规范）、**品牌拼豆色卡**
  （Hama / Perler / Artkal / Nabbi / Yant 共 13 张）、**通用近似色**（beads16/24，不属任何品牌）。
  品牌卡来自社区整理数据（[beadcolors](https://github.com/maxcleme/beadcolors)，MIT），
  **色值有据可查但不保证与实物零偏差，请以实物为准**。要严格对应手上的号色，请把自己品牌的色卡整理成
  `.hex`（每行 `编号 #rrggbb`）后导入。
- **导入的号色会真的印在图纸与清单上**：导入后「色板」分组里出现号色表，编号（如 `S12`）替代自动编号（`C1`/`C2`…）。
  号色写错了可以直接在表里改，不想要的颜色点「删」即可（颜色与号色一起删，后面的编号不会整体错位）。
- **要打印就导出 PDF**（导出 ▾ → 拼豆 → 可打印图纸 PDF）：一块板一页、A4、含格内号色与图例。
  命令行加 `--pdf` 同样可以：`node tool/artc.mjs --in 图.png --out 输出 --palette beads16 --bead --pdf`；
  用自己的色卡则写 `--palette 我的色卡.hex`。

## 游戏开发者注意

- 点「**游戏精灵**」预设（或在命令行用 `--size 32x32`）得到**精确尺寸**，帧尺寸恒等，不需要引擎侧二次对齐。
- 勾选「真 alpha」导出带透明通道的精灵图；`--sheet` 会额外输出图集坐标表（含 `offsetX/offsetY`）。
- 一批素材要共用配色请**锁定色板**，否则每张图各自取色会导致整套风格不统一。
- **图集元数据可以直接喂给引擎**：`--sheet` 出通用坐标表（`_sheet.json`），
  再加 `--engine godot` / `unity` / `tiled` 会额外产出引擎认识的格式
  （Godot `.tres` SpriteFrames、Unity `.meta` 的 spriteSheet 段、Tiled `.tsx`）。
  Unity 需要 `--texture-guid`（从你那份 `.png.meta` 里取）。页内 API 对应 `ps.exportSheetMeta()`。

## 常见问题

- **调好一套参数想复用** → 预设区的「＋ 存为预设」存成新预设；想把改动写回某个出厂预设，展开「管理预设」点「用当前参数更新」
- **原本的「游戏资产 / 拼豆图纸」模式去哪了** → 已并入右侧「预设」（点「游戏精灵」/「拼豆图纸」即可），顶栏不再有模式选择器
- **转换后发暗/发灰** → 提高颜色数（自动取色档）或加对比度/饱和度
- **色块太碎** → 开杂色清理并调大阈值，或减少颜色数
- **边缘太糊** → 降采样改「最近邻」，或降低像素数量后手动修
- **想要超大拼豆图纸** → 像素数量拉到 1024–2048；大尺寸建议关闭抖动，转换需要一两秒
- **图纸上出现了我没有的颜色** → 说明没开「锁定色板」，或用了自动取色档
- **粘贴图片没反应** → 有选区复制内容时 `Ctrl+V` 优先粘贴选区；先按 `Esc` 取消选区
- **「新建」点了没反应 / 不知道怎么建空白画布** → 已修：没画布时「新建」会直接建一张，空状态里也有「✚ 新建空白画布」按钮。见上文「还没有画布时怎么开始」
- **画布上角的折叠箭头点了没反应** → 已修：宽窗口下它是折叠/展开该列，窄窗口下是开合抽屉；箭头浮在栏外，栏收起后它仍贴在画布边上，点一下就能放回来。见上文「侧栏的折叠 / 展开箭头」
- **刷新页面后编辑丢了** → 有**自动草稿**兜着：刷新后页面顶部会出现一条「发现上次未导出的编辑（尺寸 · 时间）」提示，点**恢复**就拿回来、点**放弃**则丢弃。草稿存在本机浏览器（IndexedDB），**原图也一起存**（很大的图可能因配额存不进去，此时画布照样恢复，只是不能重新转换）。
  想长期保存仍请用「导出 ▾ → 项目 JSON」留档——草稿只是防手滑，不是归档。
