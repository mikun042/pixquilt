# 使用手册

面向**用这个工具出图的人**。不需要懂编程。

> 还没拿到 HTML？看 [README.md](../README.md) 的「给人类：三步开始用」。
> 简单说：**双击仓库根目录的 `像素画工作台.html`** 就能用（Chrome / Edge）。

---

## 1. 三分钟上手

打开后你会看到三块区域：

```
┌──────────────────────────────────────────────────────┐
│ 顶栏  导入 · 撤销重做 · 新建 · ? 快捷键 · 导出 ▾        │
├────────┬────────────────────────────┬────────────────┤
│ 左栏    │                            │  右栏           │
│ 工具    │         画  布              │  参数面板       │
│ 主色/背景│                            │  预设 / 尺寸 /  │
│ 工作色板│                            │  颜色 / 调整 /  │
│        │                            │  导出相关       │
├────────┴────────────────────────────┴────────────────┤
│ 状态栏  尺寸 · 格数 · 用量 · 光标位置                    │
└──────────────────────────────────────────────────────┘
```

**上手三步**：

1. **拖入图片**（或点画布中间的「✚ 新建空白画布」从零画）
2. **右侧调参数**（懒得分就选一个「预设」）
3. **顶栏「导出 ▾」**选你要的产物

> **参数改完要生效，需要点「重新转换」**（在参数面板上）。画布上的手动编辑不会被参数覆盖。

## 2. 两种用途

### 用途 A：拼豆图纸

给手工拼豆用。你要的是"买哪些颜色、每种几颗"。

1. 拖入图片
2. 右侧「预设」→ 选 **拼豆图纸**
3. 调「**长边格数**」—— 这是**最重要的一个数**：
   - 它直接决定成品多大、要买多少珠子
   - 58 格 ≈ 一块标准拼豆板；想小一点就用 29
   - 珠子总量大致和格数的平方成正比：58 格的图约 3300 颗
4. 点「重新转换」
5. 顶栏「**导出 ▾ → 拼豆**」：
   - **图纸 SVG + 缺口清单 CSV** —— 图纸每格标着号色，清单告诉你每种色买多少
   - **可打印图纸 PDF（A4 分页）** —— 每块板一页，**打印/送人比 SVG 稳**

**缺口清单长这样**：

```
编号,颜色,格数,珠数,估算重量(g),建议袋数
B01,#FFFFFF,1571,1571,125.68,4
B05,#4A4A4A,442,442,35.36,1
合计,10 色,3364,3364,269.12,13
```

> **想用自己的珠子色号？** 在参数面板的「色板」分组里导入一个 `.hex` 文件，
> 每行 `编号 #rrggbb` 两列（例如 `S31 #22CC44`）。导入后：
> 号色会印进图纸 / 清单 / PDF，还能**右键色块改号、删色**。
> 这样图纸上的 B01 就是你实际买的那个色号。

> ⚠️ **内建的拼豆色卡是"通用近似色"**，不是任何品牌的官方色号。
> 要严格对应你手上的珠子，请导入自己那份 `.hex`。

### 用途 B：游戏美术资产

给做游戏用。你要的是"精确尺寸的图 + 引擎能吃的图集坐标"。

1. 拖入精灵图 / 插图
2. 右侧「预设」→ 选 **游戏精灵**（这一条最关键，见下面的警告）
3. 「尺寸」选**精确尺寸**（16/24/32/48/64/128）
4. 勾上**保留透明**（真 alpha 通道）
5. 「重新转换」→ 导出 `PNG`

要**多个帧拼成图集**：把多张图放进一个文件夹，用命令行批量跑（见第 6 节），
会额外产出 `_sheet.json`（每帧的 `offsetX/offsetY`），Godot / Unity / Tiled 可直接用。

> ⚠️ **别用默认参数处理已经画好的像素图。**
> 默认参数是给"照片转像素"调的，用在像素图上**会糊掉 1px 细节**。
> 一定要选「游戏精灵」预设，或者按 [docs/agent-上手.md](agent-上手.md) 里写的手动配
> `最近邻 + 不做杂色清理 + 保留透明`。

## 3. 界面详解

### 顶栏

| 按钮 | 作用 |
|---|---|
| **导入** | 选图片文件（也可以直接把图拖到画布上） |
| **撤销 / 重做** | 也能用 `Ctrl+Z` / `Ctrl+Y` |
| **重新转换** | 用当前参数把原图重新转一遍（改了参数后点它） |
| **新建** | 空白画布 / 清空 |
| **? 快捷键** | 打开快捷键速查表（按 `?` 也行） |
| **导出 ▾** | 所有导出选项，见下 |
| 侧栏箭头 | 收起 / 展开左栏或右栏，让画布更大 |

### 导出菜单里有什么

**图片**

- `PNG 1x（原尺寸）` —— 当前画布原样导出
- `放大倍数 2x / 4x / 6x / 8x / 10x / 12x / 16x / 20x` —— 最近邻放大，**像素边缘保持锐利**
- `复制 PNG（1x）` —— 直接进剪贴板，方便粘进聊天 / 文档

**拼豆**

- `图纸 SVG + 缺口清单 CSV`
- `可打印图纸 PDF（A4 分页）`

**数据**

- `像素数据 JSON` —— 每格颜色 + 每色用量表（做原料清单用）
- `色板 .hex` —— 当前用到的颜色，可导入 Lospec 等工具
- `项目 JSON` —— 参数 + 色板 + 像素（**不含原图**），可分享给别人继续编辑

### 快捷键（完整表）

> 界面里「? 快捷键」是**唯一出处**。下表与它一致；若两者不一致，**以界面为准**。

| 键 | 作用 |
|---|---|
| `B` / `M` / `G` / `I` | 画笔 / 选区 / 填充 / 取色 |
| `U` / `O` | 矩形 / 椭圆（拖拽绘制） |
| `E` | 选中「透明色」：画笔/填充/形状即**挖洞** |
| `Tab` | 交换主色 / 背景色 |
| `Alt + 点击` | 临时取色（不切换工具） |
| 按住 `L` 点击 | 从上次落笔处画直线 |
| `M` 拖动 | 框选（`Shift` 并入选区） |
| `X` / `Del` / `Backspace` | 把选区挖成透明 |
| `F` | 选区填主色 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选区（粘贴锚点 = 鼠标格） |
| 方向键 / `Shift`+方向键 | 移动选区内容 1 / 10 格 |
| 滚轮 / `+` / `−` / `0` | 缩放 / 适配窗口 |
| 空格+拖动 / 中键拖动 | 平移画布 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 导出 PNG（1 倍） |
| `?` | 打开快捷键速查表 |
| 点主色/背景色块 | 打开取色器 |
| **右键工作色板色块** | 微调此颜色 / 替换为…（见第 4 节） |
| `Esc` | 放弃正在进行的色板微调 |

### 参数面板详解

| 参数 | 什么意思 | 什么时候动它 |
|---|---|---|
| **预设** | 一整套参数的快捷方式（照片写实 / GameBoy / 复古主机 / 黑白剪影 / 游戏精灵 / 拼豆图纸） | 先选它，再微调 |
| **长边格数** | 输出图像长边的格子数（8–2048，默认 64） | 决定成品大小；拼豆必调 |
| **尺寸方式** | 长边 / 精确尺寸 | 做游戏资产选**精确尺寸**（覆盖长边） |
| **裁剪比例** | 自由 / 1:1 / 4:3 / 16:9 | 想统一构图比例时用 |
| **缩放方式** | 区域平均 / 最近邻 | **最近邻**保住像素画的硬边；平均适合照片 |
| **颜色数** | 自动取色时用几种颜色（2–64） | 想颜色少一点、更"像素"就调小 |
| **固定色板** | 只用指定色板里的颜色 | 拼豆、成套资产必用 |
| **抖动** | 无 / Floyd-Steinberg / Bayer | 照片加 **Bayer** 有复古掌机味 |
| **杂色清理** | 小于 N 格的碎色块并入邻色 | 照片转像素后觉得脏就调大 |
| **亮度 / 对比度 / 饱和度** | 转换前的预处理（−100..100） | 原图灰、平的时候用 |
| **保留透明** | 保留原图的 alpha 通道 | 做游戏素材必勾 |
| **背景透明** | 把某个底色键控成透明 | 去掉白底用这个 |
| **合成 / 键控底色** | 指定要被去掉的底色（默认白） | 配合上一条 |
| **键控模式** | 全图 / 只去四边连通 | **白底但主体内部有同色高光（眼白等）时，必须选"只去四边"**，否则高光会被挖穿 |
| **键控容差** | 颜色差多少算同色（0–255） | AI 生图的"白底"常是 254/255 噪声，调到 1–3 才去得掉 |
| **只允许用色板里的颜色** | 锁定色板 | 拼豆 / 成套资产必勾 |

## 4. 编辑画布

- **画笔**（`B`）：按住拖动上色。选「透明色」（`E`）就是橡皮。
- **填充**（`G`）：点一下把相连的同色区域整块换色。
- **形状**（`U` 矩形 / `O` 椭圆）：拖出范围。
- **取色**（`I`）：点画布取色；或任何时候 `Alt+点击` 临时取色。
- **选区**（`M`）：框选后可复制粘贴、移动、填色、挖透明。
- **缩放平移**：滚轮缩放，`0` 适配窗口，空格+拖动平移。

### 改颜色

**点主色 / 背景色块** → 打开取色器（色轮 + 明度条 + RGB/HSV + 滑条 + Hex 输入）。
`Tab` 交换主色与背景色。

### 改色板里的颜色（右键）

在工作色板的色块上**右键**：

- **微调此颜色…** —— 改这个色板条目的值，**全图所有用它的格子实时跟着变**。
  拖动时只预览，点「完成」才落成**一条**撤销。
- **替换为…** —— 把用这个颜色的格子**换成另一个颜色**（色板条目本身不变）。

按 **`Esc`** 放弃正在进行的微调，**不占用撤销**。

> 为什么拖动时不立刻记撤销？因为调色是个连续过程，松手即提交会让一次调色产生几十条撤销，
> 历史立刻就被冲垮了。所以：**一次编辑 = 恰好一条撤销**。

### 缩放与视图

滚轮缩放、`0` 适配窗口、`+` / `−` 微调，空格或中键拖动平移。

## 5. 自动草稿：刷新不丢

编辑过程中，工作台会**每隔一小段时间自动存一次草稿**。刷新页面后如果检测到草稿，
顶部会弹一条提示，让你选**恢复**还是**放弃**。

三个要知道的点：

- 它只保**最近一次**，**不是归档**。要长期保存请用「导出 ▾ → 数据 → 项目 JSON」。
- 很大的原图可能**存不进去**（浏览器配额）。这时画布照样恢复，只是**不能重新转换**。
- 换了别的图再刷新，旧的不会复活（替换 = 新基线）。

## 6. 用命令行批量出图（不动界面）

装了 Node ≥ 22.6 就能用，**不需要 `npm install`**：

```bash
# 一批照片 → 拼豆图纸（图纸 SVG + 缺口清单 CSV）
node tool/artc.mjs --in 照片文件夹 --out 输出 --preset beads16 --long-edge 58 --bead

# 一批精灵图 → 精确 64×64、保留透明、带图集坐标表
node tool/artc.mjs --in 精灵文件夹 --out 输出 --size 64x64 --style sprite --alpha --sheet
```

输入是 **JPEG / WebP / GIF** 等非 PNG 格式时，加 `--browser-decode`（需要本机有浏览器）：

```bash
node tool/artc.mjs --in 照片 --out 输出 --browser-decode --long-edge 58 --bead
```

完整参数表：`node tool/artc.mjs --help`。
更多配方：[docs/agent-上手.md](agent-上手.md)。

## 7. 常见问题

**Q：图片会被上传到网上吗？**
不会。全部在你的浏览器里完成，不联网。CLI 也一样在本机跑。

**Q：为什么转换后细节糊掉了？**
默认参数面向"照片转像素"。做像素风素材请看第 2 节的警告——改用「游戏精灵」预设。

**Q：导出的图为什么比屏幕上模糊 / 有杂色？**
导出默认是 1 倍（和画布同尺寸）。想要大图用「放大倍数」那一排按钮，它是**最近邻**放大、
不会糊。屏幕上的显示缩放不影响导出。

**Q：去白底后主体内部出现了洞？**
白底 + 主体内部有同色高光时会发生。把「键控模式」改成**只去四边连通**。

**Q：AI 生成图的白底去不干净？**
扩散模型输出的"白"常是 254/255 噪声。把「键控容差」调到 1–3。

**Q：图纸上的号色不是我买的色号。**
内建色卡是通用近似色。在「色板」分组导入你自己的 `.hex`（`编号 #rrggbb` 两列），
或者右键色块直接改号。

**Q：能存多大？**
画布单边上限 2048 格，色板最多 256 色，撤销栈 50 帧 / 64MB（先到先算）。
导出单边上限 16384，倍数会自动降档。

**Q：能一次处理一批图吗？**
界面一次一张。批量用命令行（第 6 节），它会逐张跑。

**Q：能做动画吗？**
**不能**，多帧动画尚未实现。逐帧出图后用命令行 `--sheet` 拼成图集，在引擎里播。
