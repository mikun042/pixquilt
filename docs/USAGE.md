# 使用说明

把照片 / 插图变成像素画，再逐格精修，最后出拼豆图纸或游戏素材。**全部处理在你自己的电脑上完成。**

## 快速开始

1. 双击 `像素画工作台.html`（建议 Chrome / Edge）
2. 拖入图片（或顶栏「导入图片」，也可 `Ctrl+V` 粘贴）
3. 顶栏选模式 → 右侧调参 → 左侧工具精修 → 顶栏导出

支持格式：PNG / JPG / WebP / GIF / BMP / AVIF / ICO / SVG（浏览器原生解码）。

## 三种模式

顶栏**左侧**是模式切换，**右上角**是「导入图片」和「导出 ▾」——文件级操作都在右上角，符合桌面软件的习惯。

| 模式 | 用途 | 默认行为 |
|---|---|---|
| **图片→像素** | 通用转换 | 长边格数 8–2048，自动取色或预置色卡 |
| **拼豆图纸** | 手工拼豆 | 固定号色板 + **锁定色板**（只用你买得到的颜色）+ 58×58 格（29×29 孔大方板） |
| **游戏资产** | 引擎素材 | **精确尺寸** 32×32 + 真 alpha + 最近邻降采样 |

切换模式只是套一组参数，之后仍可自由微调。

## 顶栏

顶栏只有两处内容：**左侧是状态**（品牌 + 模式切换），**右上角是全部动作**。窗口变窄时动作按钮自动收成图标（悬停有说明）。

| 位置 | 内容 |
|---|---|
| 左侧 | 品牌 · **模式切换**（位置固定不动） |
| 右上角 | 撤销 · 重做（无步骤时自动变灰）· 重新转换 · 新建 · `? 快捷键` · **导入图片** · **导出 ▾** |

**导出 ▾** 菜单里按用途分组：

- **图片**：PNG 1x（原尺寸）、放大倍数 1x–20x 一键、复制 PNG 到剪贴板
- **拼豆**：图纸 SVG + 缺口清单 CSV
- **数据**：像素数据 JSON、项目 JSON
- **画布**：新建空白画布（不导入图片直接开画）

没有画布时菜单仍可点开，里面会直接说明该先做什么（而不是按钮变灰让人猜）。
`Ctrl+S` 等于「导出 PNG 1x」。

## 转换参数

| 参数 | 说明 |
|---|---|
| 像素数量（长边） | 输出长边格数，短边按原图比例取整 |
| 画布尺寸（格） | 拼豆/资产模式：精确 W×H |
| 色板 | **自动提取**（Median Cut）/ **预置色卡**（PICO-8、GameBoy、NES、CGA、拼豆 16/24 色）/ **自定义**；支持导入 `.hex`（Lospec 风格，或 `编号 #rrggbb` 两列带号色） |
| 降采样 | 区域平均（照片）／最近邻（硬边） |
| 抖动 | 关闭 / Floyd–Steinberg / Bayer；**开启时杂色清理自动关闭**（抖动点会被清理吞掉） |
| 杂色清理 | 把孤立小色块并入邻域主色，适合让色块成形 |
| 亮度 / 对比度 / 饱和度 | 转换前调整；照片发灰先加对比度 |
| 透明处理 | **不透明**（合成到底色）／**单色键控**（导出时该色变透明）／**真 alpha**（保留原图透明，精灵图首选） |
| 锁定色板 | 只用给定色板，绝不新增颜色（拼豆与资产批次必备） |

**风格预设**：照片写实 / GameBoy / 复古主机 / 黑白剪影 / 游戏精灵 / 拼豆图纸，一键套用整套参数。

## 工具与快捷键

| 快捷键 | 功能 |
|---|---|
| `B` / `M` / `G` / `I` | 画笔 / 选区 / 填充 / 取色 |
| `U` / `O` | 矩形 / 椭圆（拖拽绘制） |
| `E` | 选中「透明色」：画笔 / 填充 / 形状都变成**挖洞**（导出即真透明） |
| `Tab` | 交换主色 / 背景色 |
| `Alt + 点击` | 临时取色（不切换工具） |
| 按住 `L` 点击 | 从上次落笔处画直线 |
| `M` 拖动 | 框选（`Shift` 并入选区，可从画布外起手） |
| `X` / `Del` / `Backspace` | 把选区挖成透明 |
| `F` | 选区填主色 |
| `Ctrl+C` / `Ctrl+V` | 复制 / 粘贴选区（粘贴锚点为鼠标所在格） |
| 方向键 / `Shift+方向键` | 移动选区内容 1 / 10 格 |
| 滚轮 / `+` / `−` / `0` | 缩放 / 适配窗口 |
| 空格 + 拖动、中键拖动 | 平移画布 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做 |
| `Ctrl+S` | 导出 PNG（1 倍） |

- **左键画主色，右键画背景色**；笔刷 1×1 / 2×2 / 3×3（悬停有足迹预览）。
- 选区在状态栏显示格数；有复制内容时会显示「已复制选区」。
- 画布右下角有「适配 / 100% / − / ＋」浮层，鼠标用户不必记快捷键。
- 顶栏 `? 快捷键` 打开速查表——**以它为准**。

## 导出

| 产物 | 内容 |
|---|---|
| PNG（1x–20x） | 整数倍最近邻放大，格子锐利；尺寸超限自动降倍 |
| 复制 PNG | 1 倍复制到剪贴板，可直接粘进聊天/文档 |
| 像素 JSON | 每格颜色 + **每色用量表**（拼豆原料清单、素材核对） |
| 项目 JSON | 参数 + 色板 + 像素，**不含原图**，体积小可分享；对方重新导入原图即可再转换 |
| 拼豆图纸 SVG | 格内标号色、每 10 格加强线、板编号与图例；打印成黑白也能照着摆 |
| 缺口清单 CSV | 编号 / 颜色 / 格数 / 珠数 / 估算重量 / 建议袋数 / 分板 |
| `.hex` 色板 | 可导入 Lospex 等工具 |

文件名自动带源图名，例如 `照片_64x48_8x.png`。

## 拼豆用户注意

- 默认每板 **58×58 格**（对应 29×29 孔的大方板）；可按你的板子规格调整（`--board` 或用页内 API 的 `boardCells`）。
- 重量按 **5mm 豆 / 单颗约 0.08g** 估算，可用 `--bead-mm` / `--bead-gram` 改成你自己的规格。
- 内建拼豆色卡是**通用近似色**，不是某品牌官方色号。要严格对应你手上的号色，请把官方色卡整理成 `.hex`（每行 `编号 #rrggbb`）后导入。

## 游戏开发者注意

- 用「游戏资产」模式或 `--size 32x32` 得到**精确尺寸**，帧尺寸恒等，不需要引擎侧二次对齐。
- 勾选「真 alpha」导出带透明通道的精灵图；`--sheet` 会额外输出图集坐标表（含 `offsetX/offsetY`）。
- 一批素材要共用配色请**锁定色板**，否则每张图各自取色会导致整套风格不统一。

## 常见问题

- **转换后发暗/发灰** → 提高颜色数（自动取色档）或加对比度/饱和度
- **色块太碎** → 开杂色清理并调大阈值，或减少颜色数
- **边缘太糊** → 降采样改「最近邻」，或降低像素数量后手动修
- **想要超大拼豆图纸** → 像素数量拉到 1024–2048；大尺寸建议关闭抖动，转换需要一两秒
- **图纸上出现了我没有的颜色** → 说明没开「锁定色板」，或用了自动取色档
- **粘贴图片没反应** → 有选区复制内容时 `Ctrl+V` 优先粘贴选区；先按 `Esc` 取消选区
